# Agent-Native Repository

Build repositories that carry disposable human and AI contributors through durable state, deterministic verification, progressive context, narrow delegation, and reviewed automation promotion.

This directory is a self-contained incubating skill. It is intentionally independent of the product repository around it so it can later become a standalone public project.

## What it provides

- Read-only repository audit and maturity classification
- Minimal greenfield or brownfield bootstrap guidance
- Replacement-agent reorientation workflow
- Deterministic quality-gauntlet design
- Semantic tool-routing and evidence guidance
- Read-only automation-candidate discovery principles
- Portable templates and small validation scripts
- The long-form article, [The Repository Is the Runtime](references/the-repository-is-the-runtime.md)

It does not install tools, rewrite CI, collect external telemetry, create an orchestration platform, or enforce one language stack.

## Use

Install or expose the `agent-native-repository` skill to an agent host, then request a mode:

```text
Audit this repository for agent-native development. Do not change files.
```

```text
Bootstrap the smallest Level 1 agent-native control loop in this repository.
Preserve existing instructions and build commands.
```

```text
Reorient me to the active work item using repository evidence, not chat history.
```

See [EXAMPLES.md](EXAMPLES.md) for additional scenarios.

## Validate

From this directory:

```sh
./scripts/validate-skill.sh
./scripts/repository-snapshot.sh /path/to/repository
```

The snapshot is read-only. Its output reports presence, not operational proof; audit mode must execute or inspect relevant evidence before claiming a capability works.

## Incubation and publication

The skill will evolve from real use. Changes should capture transferable principles, not product-specific conventions. Before extraction, follow [references/portability-and-extraction.md](references/portability-and-extraction.md).

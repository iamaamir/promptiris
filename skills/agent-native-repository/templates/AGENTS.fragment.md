# Agent constitution

Optimize correctness and verified acceptance before efficiency. Measure total model cost per verified accepted task, not tokens per individual call.

## Prime directive

> **Reason with models.**\
> **Compute with tools.**\
> **Search structurally.**\
> **Store state externally.**\
> **Communicate through references.**\
> **Verify deterministically.**\
> **Retrieve progressively.**\
> **Delegate narrowly.**\
> **Automate repetition.**\
> **Measure everything.**

## Working rules

1. Reuse fresh evidence, then use registered automation, deterministic tools, retrieval, and finally model reasoning.
2. Prefer deltas and relevant dependency neighborhoods over rereading unchanged state.
3. Do not delegate mechanical listing, search, parsing, formatting, test execution, or exit-code inspection.
4. Preserve large logs as artifacts and communicate concise findings by reference.
5. Verify every change. A producer cannot self-certify.
6. Stop repeated identical failure loops and escalate deliberately.
7. Record operational traces without private reasoning, secrets, or unauthorized user content.
8. Treat recurring actions as reviewed automation candidates; never self-activate generated automation.

Merge this fragment with existing repository instructions. Keep stack-specific commands and conditional policy in linked documents rather than expanding the always-loaded constitution.

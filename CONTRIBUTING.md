# Contributing

Keep changes small and evidence-backed. Run `./scripts/agent-context` first,
then `./scripts/verify-candidate --ci` before submitting a change. Preserve raw
tool output under `.agent/` and report references, not large logs. Follow the
repository constitution in `AGENTS.md` and Conventional Commits with emoji.
Do not add `Co-Authored-By` or other AI/tool-attribution trailers to commit
messages. Commit authorship comes from Git history alone.

# Gate Default Enhance releases with multidimensional evidence

The bundled Recipe will not ship a strategy merely because examples look better or one model grader prefers it. A release must pass zero-tolerance mechanical invariants, blinded adjudicated semantic thresholds, and paired downstream effectiveness/non-inferiority tests across model capability classes. Results include uncertainty and exact system fingerprints.

A single scalar score would let gains in verbosity or style conceal lost constraints, invented requirements, or regressions on already-good Inputs. Requiring only perfection would be dishonest for semantic judgments and statistically impossible to generalize from a finite corpus. The profile therefore separates hard machine-verifiable safety properties from measured semantic and utility thresholds.

## Consequences

The initial release carries meaningful evaluation cost and a 400-case corpus plus 160 downstream tasks. Strategy changes become reviewable against stable evidence, local and weak-model behavior remains first-class, and claims stay bounded to tested systems. Evaluation components are extensible Plugins, but Recipe governance owns the minimum release gates.

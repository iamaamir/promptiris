# Make repository evidence the authority for agent-driven changes

Humans and models will be treated as untrusted Change Producers whose Candidate Changes become mergeable only through a repository-owned deterministic gauntlet. A small committed constitution, progressively compiled local context, isolated Work Items, commit-bound Evidence, source-blind QA, and required integration checks replace reliance on long prompts, agent memory, self-reported success, or producer identity.

This adds tooling and verification cost and deliberately limits unsafe parallelism. In exchange, weak and strong models, humans, and different agent hosts can contribute without carrying private project state; valid work is reused, repeated failures are inspectable, and quality policy remains enforceable when an agent ignores written guidance.

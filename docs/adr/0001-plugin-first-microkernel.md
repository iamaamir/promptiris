# Use a plugin-first microkernel

Prompt Iris will keep only invariant orchestration mechanics in the Kernel and express transformation policy through explicitly activated Plugins and Recipes. A richer built-in pipeline would be faster initially, but it would make prompt enhancement the architecture's permanent center and force future guards, structured transformations, providers, and host behaviors through Kernel changes; the smaller Kernel makes “everything is a plugin” an enforceable boundary rather than branding.

## Consequences

The Kernel must own strong contracts, graph compilation, failure isolation, and provenance. Built-in behavior receives no privileged extension API: Default Enhance is an ordinary Recipe assembled from the same public surfaces.
